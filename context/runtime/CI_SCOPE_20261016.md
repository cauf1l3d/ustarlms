# Активный CI и выпуск

Owner16Oct подтвердил: прод работает через local_ustar и theme_ustar. `frontend/` — legacy Next.js; исходники сохраняются, но его npm install/test/audit/build/http smoke, dependency lock и файлы исключены из активного review gate и release package. Это изменение области продукта, а не уменьшение уровня проверки native Академии.

## Обязательные проверки native source

PHP8.2/8.3 syntax и source/XMLDB/Mustache checks; Python fixtures/harness; PHP route/career contracts; JS/DOM и Playwright tests темы/плагина. Node остаётся нужен для native JS и не означает запуск legacy frontend. Workflow слушает PR в main; старые integration/codex ветки больше не самостоятельная release-очередь.

## Полный release candidate

`full-rc` label (включая последующие synchronize/reopened с сохранённой меткой) или workflow_dispatch/full_rc запускают isolated rollback, замороженный source package и fresh/upgrade/repeat/Moodle DB matrix historical+patch518. Gate зависит от source/rollback/prepare-rc/moodle-db. Ordinary source-only PR с пропущенными DB/rollback не называется полным RC. Данные synthetic; это не восстановление рабочей Академии сисадмина.

Release manifest format2 включает application_scope local_ustar/theme_ustar, native dependency locks и явное legacy_excluded. `ustar-source.tar.gz` содержит только две Moodle-компоненты. Тесты проверяют, что изменение legacy клиента не меняет native hashes/upgrade plan и не добавляет зависимость gate.

## Проверки инфраструктуры

Отдельные workflows проверяют restore lifecycle, AppArmor parser и host cold/package controllers с root-owned temporary files, real locks/tar и отдельными sleep-only systemd units. Docker/SQL/control paths в unit fixtures моделируются; не приписывать им live source pause/restore/SMTP/whole-host boot acceptance.

При сверке исправлены утечка umask между CLI-тестами и неявный выбор optional package из родительской scratch-папки. Явный USTAR_OFFICIAL_PACKAGE_FIXTURE по-прежнему обязан совпадать с pinned SHA; guard и код helper не ослаблялись. Локальное отсутствие MCP/PHP/AppArmor/systemd не скрывается под общей зелёной отметкой; окончательное evidence фиксируется по exact GitHub run/job SHA.
