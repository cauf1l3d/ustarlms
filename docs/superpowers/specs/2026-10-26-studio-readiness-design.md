# Студия: готовность к внедрению, академический интерфейс, PDF

Продолжение согласованной STUDIO-01 по поручению владельца26Oct: исправить CI, подготовить внедрение, улучшить удобство и академическое оформление, добавить PDF. Владелец выбрал редактируемый текст при импорте PDF. Остальные решения ниже — инженерные решения в рамках этого поручения.

Сохраняем native Moodle, три панели, общие проекты, права, конфликты, File API и SCORM. Не меняем роли и production. Академический интерфейс: глубокий синий, светлая бумага, сдержанный золотой акцент, читаемые подписи, одно основное действие «Сохранить в материалы». Вторичные форматы — меню файлов. Добавляем проверку пустых экранов/описаний изображений с переходом к проблеме, статистику слов и времени чтения, режим сосредоточенного редактирования и доступную клавиатурную навигацию.

## Подходы к PDF

- Локальный PDF.js для извлечения текста; печатный HTML через браузер для PDF. Выбран как минимальный вариант без новых серверных сервисов и передачи документов за пределы Академии. Пользователь выбирает «Сохранить как PDF» в печати.
- Серверный pdftotext/TCPDF потребовал бы установки/настройки runtime и отдельной поддержки сложной HTML-вёрстки; не нужен для выбранного текстового импорта.
- Изображения страниц и внешний OCR не соответствуют выбранному режиму. Сканы без текстового слоя отклоняются с понятным объяснением; сложная вёрстка требует проверки автором.

PDF: максимум25МБ/200страниц/2млн символов. Новый курс, один экран на страницу, порядок текста PDF, HTML-экранирование, источник с именем файла и номером страницы. Предпросмотр перед добавлением; пустые страницы сохраняются с предупреждением. Для полностью пустого PDF, пароля и повреждённого файла — понятная ошибка, текущий курс неизменён. PDF.js закреплён и хранится локально, JS документа не выполняется, eval отключён, worker уничтожается после обработки/таймаута. Экспорт включает обложку, содержание, экраны, иллюстрации и источники; без панелей редактора, с переносами длинного текста. Поддерживает кириллицу через шрифты браузера; PDF не содержит интерактивности SCORM.

CI: сначала безопасная серверная диагностика фактического500, затем регрессия и исправление причины. Закрытие сессии не должно предшествовать Moodle операциям, меняющим её кэши. Проверка полного HTTP пути дважды и обе Moodle матрицы обязательна. Зелёный CI означает candidate, а не production-приёмку.
