# Пульт: UI/UX для владельца

Дизайн-спецификация16Oct2026. [Архитектура](ARCHITECTURE.md) · [Метрики](OBSERVABILITY.md). [Автономный прототип](prototype/index.html) обновлён из актуального UI16Oct; [предыдущая demo-итерация](prototype/archive/index-20261015.html) сохранена отдельно. Реализация16Oct усилена после замечания владельца о нечитаемом тексте: крупнее типографика, явный контраст, цветовые акценты и панели временных рядов в духе Grafana. Browser fixtures проверяют разные экраны, размеры и масштаб подписей; native server1 пока не установлен.

## Характер интерфейса

Сдержанность Linear: чёткая структура, тонкие разделители, компактные списки и быстрые переходы. Подход Apple к взаимодействию: узнаваемые действия, достаточные области нажатия, последовательные состояния, ясная обратная связь. Важнее быстро найти причину и действие, чем заполнить экран виджетами.

Тёмный графит, контрастная типографика и постоянные смысловые акценты: HTTP — мятный, CPU — оранжевый, RAM — фиолетовый, диски — голубой, бэкапы — янтарный. Статусные цвета занимают мало места и всегда сопровождаются текстом/иконкой. Нет декоративных hero-блоков, градиентных KPI, стеклянных карточек, искусственных gauges или health score. Графики нужны для динамики; число и его смысл читаются без графика.

## Навигация

| Раздел | Главное содержание и действия |
|---|---|
| Обзор | Доступность, текущие проблемы, ресурсы, последняя копия, последние операции |
| Академия | Внешний/local response, RPS/p95/errors, DB/cron, связанные логи; контролируемые действия позже |
| Сервер | RAM/CPU/IO/network/storage, контейнеры, shared services, версии и reboot |
| Бэкапы | Last success/attempt, архивы/проверки/restore evidence, скачать/проверить/создать, SFTP/export |
| Стенды | Назначение, snapshot, адрес, доступность, TTL, ресурсы, start/stop/изменить срок |
| События | Инциденты, важные логи и операции: разные вкладки с общим временем/объектом |

Настройки и профиль внизу sidebar. Контейнеры находятся внутри «Сервер», SFTP внутри «Бэкапы», чтобы верхняя навигация оставалась короткой. Search/command palette находит страницы/объекты; destructive actions не выполняются из palette без плана.

## Первый экран desktop

1. Верхняя строка: «Обзор», среда **Production**, время/период, индикатор свежести. Рядом краткий health-текст: «Академия доступна · 1 проблема требует внимания» (пример, не текущий статус).
2. Четыре компактных состояния: Академия / Сервер / Данные / Мониторинг. Нажатие открывает проверки и причину.
3. Четыре блока ключевых чисел с единицами и цветным маркером: свободная RAM из total; CPU%; внешний HTTP response и real p95 с n; возраст последнего completed backup. Крупное число36px, читаемая подпись16px и линейный индикатор только для реально измеренной доли ресурсов; нет вымышленных health scores.
4. Два выровненных графика в духе Grafana с общим периодом: response/RPS и CPU/RAM. Панели имеют сетку, временную ось по Москве, единицы и легенду с последним/средним/максимальным значением. CPU/RAM идут отдельными линиями на шкале0–100%; HTTP — в миллисекундах. Легенда скрывает/возвращает линию; курсор и tooltip показывают значения. Пропуски сохраняются разрывами. ResizeObserver задаёт SVG реальную ширину; подписи14px не сжимаются вместе с большим viewBox.
5. Список «Требует внимания»: влияние → причина → длительность → безопасное следующее действие. При отсутствии инцидентов короткая строка, а не праздничная картинка.
6. Ниже компактная таблица production containers/активных стендов и лента последних backup/jobs. За подробностями — в раздел или drawer, не ещё десять графиков.

Критическая проблема находится выше графиков. На обычном laptop1440×900 верхний экран должен показывать health, ключевые числа и текущую проблему; второстепенные таблицы допускаются ниже fold. Не делать важные сведения доступными только по hover.

## Детали поведения

- Health badge открывает drawer: что проверено, последнее значение/возраст, порог/окно, график, связанные sanitized logs, действие. URL сохраняет объект и фильтры; Telegram приводит на тот же incident.
- «Нет данных», «устарело», «проверка не настроена», «обслуживание» имеют собственные тексты. На графике разрыв, а не нулевая линия. Историческая цифра помечена датой.
- Фильтр времени общий; при уходе в прошлое live-label меняется на «История». Auto-refresh не сбрасывает scroll/selection/раскрытый incident.
- Backup строка: snapshot date, размер, encryption, hash verification date, restore evidence отдельно. Кнопки «Скачать», «Проверить», «Создать копию» не смешиваются. «Восстановить» открывает план с target, source и последствиями.
- Stand строка: lab/permanent-copy/production, адрес и scope доступа, remaining TTL/точное выключение. Изменение TTL показывает новый deadline; unlimited не выглядит как забытый expired lab.
- SFTP: копирование host/port/user/path/fingerprint и инструкция WinSCP. Не предлагать ввод root-пароля в браузер или показ recovery key.
- Длительная операция имеет страницу с фазой/elapsed/progress, последним событием и безопасными доступными действиями. Процент только когда известен total; иначе bytes/phase. Не показывать крутящийся spinner двадцать минут без объяснения.
- Кнопка недоступна с конкретной причиной: роль, lock, stale data, неподтверждённый архив. Toast дополняет устойчивое состояние страницы; ошибка не исчезает через3секунды.

## Телефон и доступность

На380px сначала health, текущая проблема, RAM/CPU/response/backup. Sidebar превращается в видимую сетку шести разделов; таблицы становятся короткими строками с detail view. Ключевые действия имеют touch target≥44px, не спрятаны в мелкий hover-icon. Keyboard focus видим; dialogs trap/restore focus, Escape закрывает безопасный overlay. Screen reader получает label и status updates без озвучивания каждого scrape. Zoom200% и reduced-motion входят в проверку.

Макет принимается на desktop1440/1280 и mobile390/768; проверяются loading/empty/error/NoData/critical/maintenance/long job, а не только красивый green-state. Данные прототипа явно «Демонстрация»; production UI никогда не подставляет demo fallback. Первый read-only срез реализован; native приёмка остаётся отдельной.

## Поправка владельца16Oct: читаемость и графики

Цвет текста таблиц задан явно, включая strong; он не наследует чёрный из внешнего preview. Навигация использует Lucide icons. На телефоне контейнеры превращаются в строки со своими подписями; горизонтальный скролл таблицы не нужен. На1024px навигация переходит наверх, освобождая ширину под графики. Демонстрационные ряды находятся только в test/preview fixtures и не импортируются production UI. Отсутствующие реальные данные по-прежнему NoData, цифры/графики не подставляются.
