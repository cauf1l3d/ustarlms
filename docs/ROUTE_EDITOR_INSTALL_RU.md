# Редактор точки маршрута — пакет05Nov2026

Исходники app4c122d0a подготовлены от установленного719bf47c.
Установщик и архив в повторной квалификации native Moodle/PostgreSQL после исправления тестовых fixtures.
Это промежуточное состояние, не инструкция запускать старый кандидат40c5b4a0.
Финальные архив, SHA256 и команды будут внесены после успешной квалификации.
Production остаётся app719bf47c/toolaa61d595.

Работа с редактором: отдельное «Скрыть шаг / Вернуть шаг» не создаёт версию;
«Сохранить черновик» сохраняет авторскую версию, сотрудник продолжает видеть опубликованную;
«Опубликовать изменения» проверяет готовность всех условий.
Все строки обучения и их обязательность сохраняются отдельно; дополнительные SCORM/повторные настройки сворачиваются.

Для override используется «Вернуть общий вариант» по ADR0004.
Точное устранение owner invalidparameter ещё требует повторить действие на его точке после установки.
