# ADR0019 — единая Библиотека

02.11.2026. Решение в candidate LIBRARY-01; production1100 не изменён.
Основание: запрос владельца и входные lib01 архивы (см. intake review).

Один сервис чтения объединяет личные материалы (включая сохранения ленты), каталог,
дополнительное обучение и проверки знаний. Обязательный маршрут сохраняет собственные
правила, прогресс, награды и аттестации. Его вкладка ведёт в существующий маршрут.

Четыре новые таблицы: предложения, исторические права, определения проверок, попытки.
Существующие content/catalog/native/economy остаются каноническими writers. Нет второго
кошелька, сотрудников, файлового хранилища или прогресса маршрута.

Резолвер сначала проверяет активность сотрудника, публикацию и аудиторию источника.
Грант открывает коммерческое условие и никогда не заменяет ACL. Без ACL материал
сотруднику недоступен. Authoring имеет прежние ролевые полномочия. Публичная витрина
товаров доступна активному сотруднику без глобального замка point70. Для отдельного
материала можно задать gatepoint; старый catalog_mastery остаётся writer обязательной
аттестации, дополнительные товарные проверки его не вызывают.

Покупка берёт блокировку предложения перед каноническим writer кошелька, проверяет
цену и revision из формы, атомарно фиксирует списание и бессрочный грант. Новый nonce
разрешает повторную покупку после возврата; повтор старой формы не списывает снова.
Отзыв наград не отменяет покупку; долг учитывает существующая economy. Возврат —
администратор, другой actor для своей покупки; reverse ссылается на точное списание.
Руководитель выдаёт/отзывает доступ только в своей существующей области управления.
HR/HRD и admin получают capability через роли, персональные логины не используются.
Продажи по умолчанию выключены; диапазон1–25 USCOIN настраивает admin. Новая эмиссия
не вводится. Установка не раскрывает и не перепубликует материалы без правил доступа.

Лицензия проверяется на content/file/native границах. Доступная обязательная точка
имеет независимое основание доступа и не требует покупки. Закрытый повтор SCORM не
возвращается от бесплатного оффера; явная отдельная покупка/выдача может открыть его.
Moodle enrolment — технический адаптер существующего assignment writer; приостановки
и отключённые enrol instances не включаются автоматически ради Библиотеки.

Мини-проверки хранят снимок вопросов, порога и лимита попыток; только POST начинает
или отправляет попытку. Повтор идентичной отправки идемпотентен, изменение ответа
завершённой попытки запрещено. Никаких coins/XP/evidence/route completion. Автогенерация
по товарам локальная и детерминированная: реальные категории и характеристики; если
достоверных вариантов недостаточно, вопрос пропускается. Очередь после сохранения
и сверка каждые5минут обслуживают один алгоритм, старые попытки не переписываются.

UI использует реальные theme_ustar токены в светлой/тёмной теме, единый пункт навигации,
сохраняет редакторы и старые GET ссылки через перенаправления. Новый migration0200
вместо уже установленного1100. Deploy — полный guarded successor, не ручные фрагменты.
