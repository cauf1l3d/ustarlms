# Управление Библиотекой: материалы, вопросы и доступ

06.11.2026. Страница «Управление Библиотекой» доступна по прежним правам автора, проверяющего и назначающего доступ. В режиме просмотра другого сотрудника изменения закрыты.

## Материалы

Для нового предложения выберите тип, введите часть названия и нажмите «Найти материал». Переключайте страницы поиска; затем выберите материал и заполните условия. Для существующего предложения материал закреплён: меняются название, описание и условия, а другой материал оформляется отдельным предложением. Исходная аудитория и правила публикации продолжают действовать.

## Проверки знаний

Откройте «Редактор проверок знаний», заполните тему/связь и название. У каждого вопроса нужны текст,2–6непустых различных ответов и верный вариант. Пустые блоки вопросов пропускаются; пустой ответ между заполненными нужно убрать или заполнить. Неиспользованные ответы в конце можно оставить пустыми.

«Добавить вопрос» расширяет банк до100блоков. «Выше», «Ниже» и «Удалить» меняют порядок/состав, сохраняя отмеченный ответ. Число вопросов за попытку не должно превышать заполненный банк. Черновик сохраняет работу; статус «Опубликовано» включает проверку по существующим правилам аудитории/доступа. Сохранение создаёт новую версию; прежние попытки и их результаты сохраняются.

Если сервер отказал в сохранении, исправьте поля: введённые данные остаются в форме. При конфликте версии откройте текущую версию по ссылке в новой вкладке, сравните её и перенесите нужные изменения. Исходный revision не заменяется автоматически. Перед уходом с изменённой/отклонённой формы браузер предлагает отменить переход.

Старую проверку можно найти по названию в разделе «Сохранённые проверки» и открыть с любой страницы списка.

## Сотрудники и история

Введите часть имени или фамилии в поиске сотрудника. Видны только текущие доступные вам сотрудники; перевод/приостановка перепроверяются при выдаче доступа. Результат поиска сам по себе прав не предоставляет.

История ищет имя/фамилию сотрудника либо название материала. Страницы «Назад/Далее» открывают записи за пределами первых100. Статусы: «Ещё не начался» — validfrom в будущем; «Истёк» — срок закончился; «Отозван» — доступ закрыт; «Возвращён» — покупка возвращена; «Действует» — текущий срок открыт. Эти подписи не меняют права и не выполняют финансовых действий.
