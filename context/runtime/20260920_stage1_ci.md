## Найденные и исправленные проблемы

- Manifest ошибочно исключал штатный `theme/ustar/config.php`. Теперь он учитывается как исходник темы; root config и произвольные конфиги по-прежнему не входят в снимок. Проверка на собственной рабочей копии: 383 Moodle файла совпали, drift=0.
- Исторический `db/install.php` назначал capabilities до регистрации компонента. Ошибка воспроизведена [run 35512180537](https://github.com/cauf1l3d/ustarlms/actions/runs/35512180537). Порядок новой чистой установки исправлен.
- Upgrade-fixture требует явной регистрации capabilities старого baseline перед его установкой. Это записано в `baseline-preparation.log`; не заявляется, что исторический baseline сам успешно устанавливается с нуля.
- Недопустимый XMLDB empty default `route_testers.positionid` удалён из metadata. Moodle и прежде нормализовал его в отсутствие default; физическая схема проверяется сравнением fresh/upgrade.
- Неполадки сборки PHP и offline PHPUnit устраняются в тестовом bootstrap, без открытия исходящего доступа контейнеру во время тестов.
- В последнем rollback failure [run 35521595426](https://github.com/cauf1l3d/ustarlms/actions/runs/35521595426) `version.php` читался без Moodle bootstrap: `Undefined constant MATURITY_BETA`. Теперь metadata читается после установки core и загрузки config. ERR trap перенесён из Compose в shell, чтобы Compose не подставлял его переменные. Клиент dump/restore обновлён с Debian default 15 до PostgreSQL 16; измеренный клиент 16.15 совместим с тестовым сервером 16.10.

## Ограничения

- Установленный в production код, БД, moodledata и UI в этой сессии не проверялись и не менялись.
- Восстановление production backup на чистом сервере остаётся обязательным открытым gate R00; синтетическая установка его не заменяет.
- Агрегирующий job завершается ошибкой при любой неуспешной обязательной проверке. GitHub branch protection/rulesets не менялись и отдельно не подтверждены. Для обязательности перед merge требуется назначить `gate` required check.
- AMD исходники этого этапа не менялись; имеющиеся build-артефакты входят в source archive и manifest, новая сборка AMD не заявляется.
- Данные старше baseline и rollback реальных кадровых/учебных данных не мигрировались. Runtime Moodle 5.1.1 — совместимый тестовый ориентир, а не предложение обновить production core.
