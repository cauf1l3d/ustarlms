# Автономный прототип пульта

[index.html](index.html) — актуальный макет16Oct с Grafana-style графиками и исправлениями читаемости. Скачайте этот один файл через **Download raw file** и откройте в браузере. Установка, backend, npm и интернет для просмотра не нужны. GitHub показывает исходный HTML; интерактивный макет открывается из скачанного файла.

Работают шесть разделов, выбор периода, переключение линий, подсказки графиков, детали проверок, профиль и демонстрационный выход/вход. При демонстрационном входе можно указать любые непустые значения; реальные учётные данные не нужны. Все числа и события тестовые, изменения пароля не сохраняются. API-запросы заменены локальным адаптером, сетевые подключения запрещены политикой страницы.

Интерфейс собирается непосредственно из [UI](../ui/src/main.tsx), [графиков](../ui/src/charts.tsx) и [стилей](../ui/src/style.css); production API не изменяется. Synthetic state в [mock-api.ts](mock-api.ts), ряды в отдельном [fixture](../ui/tests/graph-fixtures.ts). SHA256 трёх исходных UI-файлов записан в HTML meta `ustar-ui-source-sha256`.

Пересобрать после изменения UI (Node22+, из корня репозитория):

```sh
npm --prefix server-console/ui ci
node server-console/prototype/build.mjs
node server-console/prototype/build.mjs --check
```

Последняя команда проверяет совпадение сохранённого HTML с результатом сборки. Собранный файл включает React, иконки, CSS и данные, дополнительных файлов для просмотра не требует.

[Старый прототип15Oct](archive/index-20261015.html) сохранён без изменений. Ни один прототип не устанавливает рабочий пульт на server1. [Установка рабочего пульта](../INSTALL.md) и native приёмка выполняются отдельно.

Проверка16Oct: Chromium открывает файл через file:// без сети на1440/1024/390/320px; работают шесть разделов, графики/периоды/линии/tooltip, health-details, профиль и demo-вход/выход. Ошибок страницы и внешних запросов не обнаружено; горизонтального переполнения нет. Повторная сборка совпала с сохранённым HTML.
