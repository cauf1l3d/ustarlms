## 2. Материалы / Библиотека — обязательная UX доработка

Текущий вариант с маленьким блоком файлов НЕ является целевым.

Нужно сделать интерфейс материалов полноценным рабочим пространством.

TARGET:

- вкладка «Материалы» должна занимать всю доступную область страницы;
- файлы и папки должны отображаться как файловый менеджер, а не маленькая карточка внутри страницы;
- редактура должна открываться по нажатию на элемент;
- пользователь должен понимать структуру папок визуально;
- должна быть возможность перемещения файлов между папками;
- должна быть возможность перемещения файлов обратно из папки в корень/другую папку;
- поведение должно быть аналогично Windows Explorer:
  - drag & drop;
  - перемещение;
  - открытие папок;
  - возврат назад;
  - контекстные действия.
