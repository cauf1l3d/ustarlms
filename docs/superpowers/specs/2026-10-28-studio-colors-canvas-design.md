# Цвета курса и высота редактора

Поручение владельца28Oct и три скриншота: настраивать конечное оформление курса,
включая левое меню; скрывать название/синхронизацию, освобождая высоту полотна.
Исполнение/push разрешены в текущем диалоге; без дополнительного approval-цикла.

## Решение

Расширить существующее «Оформление» четырьмя необязательными HEX-полями темы:
navBackground, navText, navActive, navAccent. Цвета попадают в тот же проект,
общую синхронизацию, историю/копирование, предпросмотр и оба SCORM builders.
Фон страницы, фон курса, текст и акцент уже существуют; исправить оставшиеся
жёсткие цвета плеера, чтобы настройки одинаково работали в выгрузке и Академии.
Текст активного пункта подбирается по контрасту. Мини-пример меню в свойствах
показывает результат. Сброс — существующая кнопка фирменного оформления.

Варианты: менять общий CSS Академии затронуло бы другие разделы; отдельный
конструктор темы дублировал бы модель. Выбран существующий объект theme с
необязательными полями и теми же API. Старые проекты не получают новых полей
при чтении: их fingerprint должен остаться прежним, иначе синхронизация отвергнет
подлинную серверную редакцию. PHP проверяет необязательные поля до вставки в CSS.

В панели управления полотном постоянная кнопка «Скрыть шапку»/«Показать шапку» сворачивает
оба верхних блока целиком. Компактный статус остаётся рядом; нажатие раскрывает
подробности синхронизации. Кнопка работает независимо от «Сосредоточиться».
Предпочтение хранится в существующем per-user/site ui storage. Conflicts/signin/
account change раскрывают блок с доступными действиями; ошибка не скрывается.
Основные действия доступны после раскрытия шапки. Само редактирование/выделение,
позиция прокрутки и фокус не сбрасываются. Инструменты и полотно остаются внутри
адаптивной высоты Академии, учитывая нижнюю телефонную навигацию.

Новая source-версия local2800, theme2700 без изменений. Нет новой схемы/таблиц,
миграций проектов, изменения прав/Connect или SSH. Старые установщики2600/2700
остаются фиксированными; новый source не объявляется установленным по скриншотам.
