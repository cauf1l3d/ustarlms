# USTAR Academy

Корпоративная академия на Moodle: обучение, адаптация, задачи, знания и развитие.
Канонический код — local_ustar и theme_ustar; Connect обслуживает каналы Академии,
server-console — операции хоста. frontend сохранён как неактивный legacy.

Начать с [START_HERE](START_HERE.md). Там текущие версии, квитанции, архитектура,
открытые риски и очередь. [AGENTS](AGENTS.md) содержит правила изменения проекта.

Слияние в main обновляет репозиторий. Применение на сервере требует отдельной
проверенной поставки и квитанции владельца; не разворачивать HEAD автоматически.
