# Общая студия курсов — PR107

26 октября 2026. Кандидат на поставку, не подтверждение установки на production.

## Для автора

В «Материалах» нажмите «Студия курсов». Доступ соответствует текущим авторам материалов; новых ролей нет. Проекты общие для всех авторов, вход через Академию. Учётная запись ChatGPT не нужна.

1. Откройте существующий проект, создайте курс или импортируйте `.rcproject` / `.rcworkspace`. Для первого переноса загрузите предоставленный workspace (11 курсов / 153 экрана). Пользовательский workspace не входит в Git и не импортируется автоматически при обновлении.
2. Редактируйте экраны, изображения, шрифты и оформление в прежнем трёхпанельном интерфейсе. Дождитесь статуса синхронизации.
3. При конфликте сохраните обе редакции или скачайте резервную копию. Не закрывайте вкладку с несохранёнными правками.
4. «Сохранить в материалы» собирает SCORM сохранённой редакции. Откройте карточку материала, проверьте папку и аудиторию; публикация выполняется отдельно.
5. Для изменения опубликованного курса создайте копию. Публикация и существующая история прохождения не сбрасываются сохранением черновика.

«Сохранить проект» / «Скачать все проекты» создают переносимые копии с ресурсами. «Экспорт SCORM» создаёт готовый ZIP. Редактирование поддерживает совместимые SCORM USTAR (`editor.json` / `window.COURSE`); произвольный SCORM другого конструктора не превращается в редактируемый проект.

## Установка и приёмка

Использовать штатный процесс deployment Академии для проверенного exact SHA PR107 после успешного full RC. Требуется весь каталог `moodle/local/ustar`, включая `course_studio/` и vendor JSZip. Не копировать отдельные PHP без assets. Версия плагина `2026102600`, новая схема не требуется. Выполнить штатный Moodle CLI upgrade и очистку кешей от владельца web runtime; пути и способ доставки сверить с фактическим deployment сервера.

На тестовой копии: вход автора и отказ сотруднику; импорт workspace; проверка текста/изображений/шрифтов; сохранение с двух браузеров; конфликт без потери обеих редакций; подготовка материала дважды без дублирования SCORM; папка/аудитория/публикация; запуск сотрудником и сохранение прогресса. Тестовый импорт создаёт реальные черновики, поэтому не выполнять его автоматически на production.

Откат — только штатным проверенным paired backup/restore. Сохранить workspace перед работой. Не удалять новые черновики/ресурсы SQL-командами: они связаны с каноническими материалами и историей.

## Проверки и границы

Локально: `python scripts/ci/source_checks.py`, `npm test --prefix tests/release_20260912`, `php tests/release_20260912/course_studio_codec.php`. Переменная `USTAR_STUDIO_WORKSPACE` включает проверку собственного файла без включения его содержимого в Git. Stage HTTP сценарий подключён к `authenticated_shell_smoke.sh` и работает только в изолированном runtime. DOM-тест проверяет запуск и сохранение, но не заменяет визуальную приёмку браузером и проверку на сервере владельца.
