# Architecture Boundaries


## Moodle Core

Отвечает:
- базовая LMS функциональность

Не изменять без необходимости.


## local/ustar

Основной бизнес-слой.

Здесь находятся:
- маршруты
- адаптация
- организация
- экономика


## Theme

Только представление.

Не хранить бизнес-правила.


## Database

Изменения:
- через upgrade.php
- с фиксацией решения
