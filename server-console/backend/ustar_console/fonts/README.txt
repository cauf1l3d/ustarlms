Ustar Sans Regular / Bold

Portable, renamed subsets of the locally supplied DejaVu Sans 2.37 fonts.
No runtime system font lookup or network fetch is used. The complete original
Bitstream license is in LICENSE.txt; DejaVu changes are public domain.

Build input: DejaVuSans.ttf and DejaVuSans-Bold.ttf from fonts-dejavu-core.
Build tool: fontTools.subset 4.61.1; retain all name records and language records.
Retained characters: U+0020-024F, U+0400-052F, U+2000-206F, U+20AC, U+2116,
U+2190-2193, U+2212, U+2264-2265 (only glyphs present in the source).
After subsetting, rename name IDs 1/16 to Ustar Sans, 2/17 to Regular or Bold,
3 to Ustar Sans Subset <weight> 1.0, 4 to Ustar Sans <weight>, and 6 to
UstarSans-<weight>. Original copyright and license records are preserved.
These subsets are intended only for the fixed Latin/Cyrillic operator cards.
