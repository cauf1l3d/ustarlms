# Аватары сезона и масштаб логина

База: PR73 `fb4036f53928749f42cbaffbfc2f925ada8a7551`,
local_ustar 2026100201 / theme_ustar 2026100102.
Кандидат: local_ustar 2026100202 / theme_ustar 2026100201.

Рейтинг сезона использует текущие пользовательские фотографии через штатный
Moodle user_picture / File API. Имена и фото читаются после фильтрации участников
сезона и действующих учётных записей, без дополнительного запроса на каждого
участника для получения фото. Без загруженной фотографии показываются инициалы.
Общий стиль, скрывавший инициалы и рисовавший точку, переопределён только внутри
сезонного рейтинга. Аудитория, баллы, места и проверки доступа не меняются.

На логине исходная левая карточка целиком вписана в собственные пропорции,
без второй рамки и пустых полос сверху/снизу. Маскот и исходная графика сохранены.
Правая карточка остаётся штатной формой Moodle с восстановлением, гостевым входом,
языком, cookies и внутренней регистрацией. На мобильном форма остаётся первой.
Общий фон — третье предоставленное владельцем изображение от 02.10.2026,
1672×941; WebP lossless сохраняет все пиксели, что проверено сравнением RGBA.
Оба пути изображения формируются через moodle_url, включая установки в подкаталоге.

## Установка

После зелёного полного CI на точном SHA:

```bash
bash deploy_avatars_login.sh FULL_REVIEWED_COMMIT_SHA
```

`scripts/release/deploy_avatars_login.sh` принимает только точную побайтную базу
PR73 с указанной парой версий. Перед заменой проверяет PHP, делает согласованный
backup БД/кода/moodledata, затем upgrade, очистку кешей, перезапуск OPcache,
сборку CSS и повторную сверку manifest/версий. При ошибке после установки
maintenance сохраняется; откат должен восстановить согласованный backup целиком.
Новых таблиц, ролей и изменений Moodle core нет.

## Проверка после установки

1. Выйти и открыть логин: общий предоставленный фон, целая левая карточка без
   пустых полос; форма и все действия доступны, нет горизонтальной прокрутки.
2. Проверить вход и сообщение об ошибке, восстановление и регистрацию.
3. Под участником сезона открыть «Достижения»: подиум и строки показывают фото
   из профилей; без фотографии видны инициалы, своё имя сохраняет отметку «Вы».
4. Поменять фотографию через обычный профиль Moodle и обновить рейтинг:
   штатный URL с revision должен отразить новую фотографию.
