# UI/UX ревью пульта — 16 октября 2026

Проверена реализация PR103 на исходном коммите `9d1271a9f3a6f4b9a989fc9ab0b6a7bae5e8a8c4`: шесть разделов, окно учётной записи, детали проверок, графики и мобильная навигация. Ширины: 1440, 1024, 768, 390 и 320 CSS px. Данные — browser/preview fixtures, не измерения server1.

Основная проблема подтверждена: предыдущая поправка увеличила крупные числа, но не установила последовательную читаемую типографику. На обзоре1440px осталось84 текстовых элемента меньше15px, включая оси графиков. Основной текст не терял контраст в проверенном рендере: минимальное измеренное отношение было7.73:1. Повторная жалоба объясняется размером, тесной компоновкой и наложением полей; сама замена палитры этого не решает.

## Находки и исправления

| Приоритет | Проблема до ревью | Изменение |
|---|---|---|
| P1 | Подписи, служебные строки и легенды11–13px; установленный body16px переопределён десятками локальных правил | Весь видимый интерфейсный текст от16px; оси графиков14px в реальных экранных пикселях. Заголовки панелей19–20px, значения метрик32–37px. У вспомогательного текста задан межстрочный интервал |
| P1 | На390px подпись «Восстановление» в бэкапах заходит в значение. Длинный архив и hash разрезаны узкой колонкой | На телефоне пары «подпись → значение» идут вертикально на всю ширину, в том числе в диалогах. Переносы длинных значений и отдельный контрастный фон hash |
| P2 | Четыре колонки легенды ужимаются; на320px среднее значение вообще скрывается | Легенда перестраивается по ширине самой панели. Все три значения сохраняются; на узких панелях подписи и числа расположены строками. Число отметок времени зависит от доступного места |
| P2 | При скрытии линии тускнеет вся строка с числами | Отключение обозначается перечёркнутым названием, пустым маркером и aria-pressed; контраст цифр сохранён. Если скрыты все линии, показана причина пустого графика |
| P2 | Мобильное меню скрывает несколько разделов за горизонтальной прокруткой | Все шесть разделов видны в сетке; на320px две колонки. Кнопки сохраняют область нажатия не менее44px |
| P2 | Карточка состояния сообщает о нескольких проверках, но открывает только первую | Диалог перечисляет все проверки выбранного направления с результатом, причиной и временем; Escape возвращает фокус к карточке |
| P2 | Фильтр периода есть в бэкапах, стендах и событиях, хотя ни на что там не влияет | Фильтр показывается только в обзоре, Академии и сервере, где он меняет графики |
| P2 | Пустой массив служб оставляет один заголовок без объяснения | Показано явное состояние «Состояние служб ещё не получено» |

Дополнительно: короткие непротиворечивые подписи счётчиков, русское название роли, отсутствие технического обещания о нулях в пользовательском empty-state. Смысловые цвета HTTP/CPU/RAM/дисков сохранены.

## Проверка и границы

- Локальный результат: UI build PASS, 18 browser scenarios PASS; после финальной настройки ширины легенд ещё3 проверки всех экранов на1440/1024/768/390/320px PASS. Context integrity PASS (526 исходников Академии,93 таблицы,33 задачи).
- Browser regression проверяет текст всех разделов и диалогов: фактический размер, контраст с учётом фона/прозрачности, выход за viewport и пересечение текстом границы поля. Проверяется также узкий320px экран и отключённая линия RAM.
- Проверки графиков сохраняют реальные размеры SVG-подписей, переключение рядов, tooltip, общий период и пропуски. Среднее значение доступно и на телефоне.
- Шесть разделов, вход/выход, stale/NoData, потеря соединения и окончание сессии включены в browser suite. UI build и context integrity проверяются перед публикацией; результаты закреплены в PR103 на опубликованном коммите.
- Превью дополнительно просмотрено со стилями среды показа, чтобы проверка не ограничивалась изолированной страницей без внешнего оформления.
- Это проверка Chromium и исходников, не полная сертификация доступности. Safari/Firefox, физические телефоны и индивидуальные настройки крупного системного шрифта требуют отдельной приёмки.

Backend/auth/collector, Moodle и server1 в этом ревью не изменяются. Отсутствующие реальные источники продолжают показывать NoData; синтетические графики существуют только в fixtures/превью.
