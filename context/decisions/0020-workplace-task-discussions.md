# ADR 0020 — Обсуждение как часть задачи

22.11.2026. Дополнение к [ADR 0012](0012-work-chats-mobile.md).

Сообщения и вложения хранятся в Moodle Message API и File API. Каноническая запись
`local_ustar_learning_tasks` определяет доступ к обсуждению. Переназначение задачи
сразу меняет права на новые запросы к истории, оригиналам и миниатюрам. Личные
заметки в обсуждениях не участвуют. Обычные групповые чаты используют членство,
правила добавления участников и настройки приватности Moodle.

Обсуждение создаётся при первой отправке как выключенная нативная беседа.
`itemtype=local_ustar_task_discussion` связывает её с `itemid` задачи. Нативная
панель сообщений не перечисляет беседы без постоянного членства. Для вызова
штатной записи Moodle отправитель добавляется и удаляется внутри одной транзакции.
Отправка использует тот же замок `learning-task:<id>`, что переназначение, и
сохраняет сообщение, файлы и квитанцию повтора вместе. Участники получают доступ
через задачу и раздел «Чаты задач» в Академии. Уведомления о действиях по задаче
и встречам используют существующие каналы. Сообщения чата доступны в веб-интерфейсе.

Открытый чат сверяет до 50 идентификаторов сообщений. При изменении сервер
возвращает тела, которых у клиента ещё нет. Опрос видимого диалога идёт с
интервалом 5–20 секунд. История идёт по паре `(timecreated, id)` и использует
существующий индекс Moodle. Выбор последних сообщений для списка
чатов использует `LATERAL` на поддерживаемом PostgreSQL. Вне видимой вкладки,
в поиске, старой истории и при воспроизведении медиа фоновые запросы приостанавливаются.

В «Моём плане» настройка Moodle хранит колонки и ссылки на текущие назначения.
Реестр задач остаётся источником срока, статуса, отчёта и результата проверки.
Форма встречи показывает занятость комнаты и сотрудников. Под общим замком
запись повторно проверяет комнату и организатора, а принятие приглашения
проверяет календарь участника.

Таблицы и Moodle core сохранены. Нативные обновления проверяют отсутствие
постоянного членства, повтор запроса, приватность задач и смену доступа к файлам.
Privacy API экспортирует личный план, авторские сообщения и вложения. Сведения
об установке и замерах рабочего сервера фиксируются отдельно в STATE.
