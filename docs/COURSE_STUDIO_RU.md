# Общая студия курсов — PR107

27 октября 2026. Кандидат на поставку, не подтверждение установки на production.

## Для автора

В «Материалах» нажмите «Студия курсов». Доступ соответствует текущим авторам материалов; новых ролей нет. Проекты общие для всех авторов, вход через Академию. Учётная запись ChatGPT не нужна.

1. Откройте существующий проект, создайте курс или импортируйте `.rcproject` / `.rcworkspace`. Для первого переноса загрузите предоставленный workspace (11 курсов / 153 экрана). Пользовательский workspace не входит в Git и не импортируется автоматически при обновлении.
2. Редактируйте экраны, изображения, шрифты и оформление в трёхпанельном интерфейсе с академическим оформлением. Дождитесь статуса синхронизации.
3. При конфликте сохраните обе редакции или скачайте резервную копию. Не закрывайте вкладку с несохранёнными правками.
4. «Сохранить в материалы» собирает SCORM сохранённой редакции. Откройте карточку материала, проверьте папку и аудиторию; публикация выполняется отдельно.
5. Для изменения опубликованного курса создайте копию. Публикация и существующая история прохождения не сбрасываются сохранением черновика.

«Файл → Скачать редактируемый проект» / «Скачать все проекты» создают переносимые копии с ресурсами. «Экспорт SCORM» создаёт готовый ZIP. Редактирование поддерживает совместимые SCORM USTAR (`editor.json` / `window.COURSE`); произвольный SCORM другого конструктора не превращается в редактируемый проект.

## PDF и удобство

- «Файл → Импорт PDF в текст»: выберите PDF, проверьте извлечённый текст и нажмите «Создать курс из текста». Одна страница становится одним экраном нового курса. Текущий проект сохраняется. Названия экранов можно изменить после импорта.
- Импорт: до25МБ/200страниц/2млн символов, с дополнительной проверкой серверных лимитов HTML и проекта в UTF-8. Сканы без текстового слоя нужно предварительно распознать (OCR); PDF с паролем — сохранить разрешённой копией без пароля. Изображения, таблицы и сложная вёрстка не извлекаются. Пустые страницы смешанного PDF сохраняются с предупреждением; проверьте порядок текста.
- «PDF»: открывает печатный учебный материал с обложкой, содержанием, экранами, изображениями и источниками. Нажмите «Сохранить PDF / печать» и выберите «Сохранить как PDF» в окне браузера. Формат A4, колонтитулы браузера отключить. Интерактивность SCORM в PDF не переносится.
- PDF обрабатывается локально в браузере. Все зависимости размещены внутри Академии; внешние сервисы и CDN не используются.
- «Проверить» показывает пустые экраны и изображения без описаний; нажатие замечания открывает нужный экран. Внизу листа — слова и время чтения. «Сосредоточиться» скрывает панели и освобождает место для текста; повторное нажатие возвращает их.
- На телефоне панель действий прокручивается по горизонтали. «Файл», PDF и проверка доступны в этой панели. Используйте режим сосредоточенного редактирования для работы с текстом.

## Установка и приёмка

Использовать штатный процесс deployment Академии для проверенного exact SHA PR107 после успешного full RC. Требуется весь каталог `moodle/local/ustar`, включая `course_studio/` и локальные vendor JSZip/PDF.js. Не копировать отдельные PHP без assets. Версия плагина `2026102600`, студия не добавляет таблиц; миграции актуального main сохраняются. Не устанавливать старый candidate поверх принятого Connect без объединённого main. Для статических `.mjs` сервер должен возвращать JavaScript MIME type; это проверяется браузерным импортом PDF. Выполнить штатный Moodle CLI upgrade и очистку кешей от владельца web runtime; пути и способ доставки сверить с фактическим deployment сервера.

До поставки: полный RC обеих Moodle матриц и context gate на итоговом SHA должны завершиться успешно.

На тестовой копии: вход автора и отказ сотруднику; импорт workspace; проверка текста/изображений/шрифтов; сохранение с двух браузеров; конфликт без потери обеих редакций; подготовка материала дважды без дублирования SCORM; папка/аудитория/публикация; запуск сотрудником и сохранение прогресса; PDF с кириллицей/несколькими страницами/сканом/паролем/повреждением; экспорт PDF с изображениями и источниками; работа клавиатурой и на телефоне. Проверить отказ подготовки без sesskey и отсутствие `USTAR_STUDIO_FAILURE`/предупреждений об изменении закрытой сессии в серверном логе. Тестовый импорт создаёт реальные черновики, поэтому не выполнять его автоматически на production.

Откат — только штатным проверенным paired backup/restore. Сохранить workspace перед работой. Не удалять новые черновики/ресурсы SQL-командами: они связаны с каноническими материалами и историей.

## Проверки и границы

Локально: `python scripts/ci/source_checks.py`, `npm test --prefix tests/release_20260912`, `php tests/release_20260912/course_studio_codec.php`. Переменная `USTAR_STUDIO_WORKSPACE` включает проверку собственного файла без включения его содержимого в Git. Stage HTTP сценарий подключён к `authenticated_shell_smoke.sh` и работает только в изолированном runtime. DOM-тест проверяет запуск, редактирование, проверку курса и подготовку материала. Реальный browser-тест проверяет кириллицу в PDF, импорт двух страниц, редактирование, печатный экспорт, отказ повреждённому файлу и отсутствие горизонтального переполнения на телефоне. Эти проверки не заменяют приёмку на сервере владельца.
