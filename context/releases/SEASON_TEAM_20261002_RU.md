# Имена в сезоне и варианты ответа «Кто есть кто?»

База: установленный пользователем PR72
`971be902c4554539650aafc39e81fbc61354de7b`, local/theme 2026100102.
Новый local_ustar: 2026100201; theme_ustar: 2026100102.

В «Достижениях» участники текущего сезона видят реальные имена. Своя строка
подписана «Вы». Это действует для уже опубликованного сезона без его пересоздания.
Баллы, места и аудитория не меняются. Доступ остаётся у участников своего сезона.

В тесте «Кто есть кто?» один вариант заменяет одинаковые названия должностей,
включая «Зав.склад» / «Завсклад» и «Контролер» / «Контролёр». Ответ засчитывается
для обоих исходных ID должности. «Контролер/зам. Завсклада» остаётся отдельным.
Кадровые назначения и история прохождений не меняются.

## Установка

Только после зелёного full-rc на точном SHA кандидата:

```bash
bash deploy_season_team.sh FULL_REVIEWED_COMMIT_SHA
```

Скрипт `scripts/release/deploy_season_team.sh` проверяет version pair и полный
побайтный manifest базы, делает согласованный backup БД/кода/moodledata,
проверяет PHP до замены, устанавливает изменённые файлы, сбрасывает OPcache,
выполняет upgrade/cache purge и проверяет установленный manifest/version pair.
Отчёт и backup сохраняются в домашнем каталоге. При ошибке после замены файлов
оставляет maintenance включённым; нужен согласованный откат всех частей backup,
а не подмена одного PHP-файла после upgrade. Новых таблиц/ролей нет.

## Проверка после установки

1. Участник текущего сезона: «Достижения» показывают имена, свою отметку «Вы»,
   прежние баллы и совместные места. Организатор видит те же баллы в студии.
2. Сотрудник вне сезона не получает его персональный рейтинг.
3. Работник склада РЦ: открыть «Кто есть кто?», проверить отсутствие повторных
   «Завсклад» и «Контролёр». Выбрать правильные ответы и проверить результат.
4. Открыть «Главную», сообщения и маршрут, убедиться в обычной работе.
