## Риски, влияющие на запуск

- **Смена доступа.** Список участников отдельного чата нельзя автоматически
  считать правами по задаче. Поэтому обсуждение каждый раз читает текущие права
  задачи. Название приватной встречи в проверке занятости никому дополнительно
  не раскрывается. Прежний исполнитель после переназначения теряет доступ,
  если другое действующее право его не сохраняет.
- **Сессии и запросы.** Повторная сборка истории тормозит активный чат и конкурирует
  за сессию с загрузкой файлов. Новый API закрывает запись сессии перед работой
  с данными, обновляет ограниченное окно истории и повторяет запрос после
  временной серверной ошибки. SW онлайн-режима не хранит приватные чаты.
- **Файловая нагрузка.** Проекция чата ограничивает работу с метаданными. Оригинал
  отдаёт File API, миниатюра привязана к хешу. До пилота нужно замерить реальный
  рост `filedir` и резервных копий, p95 скачивания, количество параллельных загрузок,
  лимиты внешнего прокси/PHP и поведение настроенного антивируса.
- **История.** Поиск в чате охватывает 2 000 последних видимых сообщений,
  более ранняя история открывается по страницам. Один файл до 25 МБ при
  достаточном лимите PHP, до 50 МБ и пяти файлов на сообщение. Полный архивный
  поиск, крупные возобновляемые загрузки, поиск по вложениям и упоминания
  пользователей — отдельные решения, если их потребует рабочий пилот.
- **Участники задачи.** Карта ролей требует сверки на реальных поручениях.
  Наблюдателям и соисполнителям из старой системы нельзя автоматически выдавать
  управленческий доступ к Академии. Действующие поручения с несколькими людьми
  разбирают по ответственности и доступу до переноса.
- **Переключение системы.** Покрытие сценариев проверяют на данных закрытого
  пилота. Историю сотрудников, сообщения и файлы из Битрикс24 для ревью не
  выгружали. Нужны согласованные выгрузки, карта идентификаторов и сверка прав.

Решение и границы хранения зафиксированы в [ADR 0020](../../decisions/0020-workplace-task-discussions.md).
Приёмка ролей, замеры и порядок переезда описаны в [руководстве](../../../docs/WORKPLACE_MIGRATION_RU.md).
