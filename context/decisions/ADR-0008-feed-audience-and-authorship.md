# ADR-0008: аудитория и авторство ленты (черновик G06)

Статус: предлагается; runtime и продуктовая приёмка не выполнены.

1. Лента — отдельный домен внутри `local_ustar`, а не второй каталог материалов или отдельная база задач. Идентификатор автора действия всегда Moodle user ID; видимый издатель — человек, подразделение или Академия.
2. Личный пост доступен активным сотрудникам; пост подразделения — действующим сотрудникам подразделения и руководителям с действующей областью управления; пост Академии — всем активным сотрудникам или явно выбранным подразделениям. Перевод/увольнение меняет чтение немедленно. Черновик виден только автору.
3. `feedpublishdepartment` само по себе недостаточно: требуется текущая область `organization_model::manager_scope`. Название должности никогда не выдаёт полномочие. В начальной миграции это право никому автоматически не назначается — назначение руководителям должно быть отдельным управляемым решением.
4. `feedpublishacademy` и `feedsetaudience` выдаются системным ролям HR и HRD. Для генерального директора и ассистента требуется явное сопоставление роли и назначение прав, а не вывод по строке должности. `feedmoderate` не следует из права публикации и отдельно назначается администратором.
5. Репост хранит ссылку на исходник, а SQL отсекает недоступный оригинал до лимита. Прямой просмотр, скачивание файла и социальные действия повторяют ту же проверку. Изменение аудитории будет отдельной командой с повышением `audienceversion` и аудитом; первая редакция не допускает расширения аудитории редактированием.
6. Вложения — Moodle File API в области `feed_attachment`, доступ через `pluginfile` после ACL, принудительное скачивание и `nosniff`. Первая редакция прикрепляет файлы при создании; замена должна создавать новую версию, а не перезаписывать старую.
7. Пост/комментарий удаляются мягко; события хранят actor/action/reason без бессрочной копии текста. Срок хранения, экспорт и удаление данных Moodle Privacy API ещё требуют реализации до freeze RC.

Открытые решения владельца перед выпуском: назначить manager capability по конкретным ролям/людям; выделить роли CEO и ассистента и выдать им академические права; подтвердить начальную политику видимости и retention. Черновой PR с этим ADR не устанавливать на production.
