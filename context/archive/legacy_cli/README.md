# Одноразовая HR-миграция 2724

`hr_canonical_2724_apply.php` здесь — точная историческая копия одноразовой миграции. Она не входит в рабочий каталог `moodle/local/ustar/cli/`, не предназначена для повторного исполнения и сохранена как свидетельство для инженерного аудита. По прежнему пути находится блокирующая заглушка с кодом завершения 78.

Остальные команды CLI требуют отдельной классификации по A05: наличие `probe`, `check` или `validate` в имени само по себе не гарантирует отсутствие записи в базу. Не считайте это архивирование завершением A05.
