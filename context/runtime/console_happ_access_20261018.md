## Если телефон имеет прямой доступ к офисному серверу

В существующем редактируемом профиле маршрутизации Happ для активной подписки проверить, куда попадает `192.168.1.60`. Если он ошибочно направляется через провайдера, добавить только `192.168.1.60/32` в Direct IP / «Прямое подключение». Убедиться, что более раннее proxy/block правило не перехватывает этот IP; другие списки и порядок глобально не перестраивать. Сохранить прежнее значение для отката. Это условная проверка после подтверждения офисной доступности, не установленный диагноз текущего телефона.

Сохранить профиль, выполнить Reconnect. Telegram должен остаться через существующий VPN, а конкретный LAN-адрес — идти напрямую. Сначала открыть `https://192.168.1.60:8443` в Safari с включённым VPN, затем кнопку пульта в Telegram. Доверие существующему CA на iPhone проверяется отдельно по [инструкции](../../server-console/ACCESS_FIX_20261018.md); исключение маршрута не исправляет сертификат.

Не импортировать новый полный routing-профиль поверх работающего: отсутствующие параметры Happ может заполнить значениями DNS/геобаз по умолчанию. Если подписка имеет JSON Restricted Mode, обычный ручной импорт/копирование профиля недоступны: не удалять подписку, сначала установить тип профиля и доступные настройки. Полный subscription URL, UUID и токены в чат/репозиторий не передавать.

## Если телефон дома или в мобильной сети

Direct-исключение не создаст маршрута в офисную LAN. Для Mini App потребуется отдельно согласованный защищённый канал к серверу через контролируемый внешний узел/приватный маршрут. Покупка обычной NovaVPS-подписки сама по себе такого узла под нашим управлением не подтверждает. Существующий [home-access plan](../../server-console/HOME_ACCESS_PLAN_20261018.md) остаётся кандидатом без установки. Не менять server1 routes/DNS/firewall/TUN и корпоративные входящие порты ради проверки. Графические карточки бота остаются доступным отдельным каналом.

Офисная сеть и работа в обоих VPN-режимах теперь подтверждены владельцем. Отдельный домашний/мобильный маршрут этим результатом не проверен; текущий рабочий офисный доступ не требует его реализации.
